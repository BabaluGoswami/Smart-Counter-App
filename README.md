# 🔢 Smart Counter App

A simple and interactive Counter Application built using HTML, CSS, and JavaScript. 
This project demonstrates DOM Manipulation and Event Handling by allowing users to increase, decrease, and reset the counter value dynamically.

## 🚀 Features
- Increase Counter Value
- Decrease Counter Value
- Reset Counter Instantly
- Dynamic UI Updates using DOM Manipulation
- Simple and User-Friendly Interface

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (DOM Manipulation)
